# 게임 시스템

### 게임 룰
- **영업 시작과 영업 마감 (9 A.M~6 P.M)**
- **목표 매출(200,000)**을 찍을 때까지 하루를 반복
- **평점 3** 미만으로 내려가거나 **해당 일자의 기본 비용**을 지불하지 못하면 게임 오버
- **추후** : 점포 발전 요소 추가 (음식 종류, 할 일, 자동화, 점포 크기 증가 등)


### 영업 시작
- **주문** : 주문을 받지않은 손님을 클릭하여 주문 받음 
(화면 좌상단에 (테이블 번호:만들어야하는 개수) 형식의 테이블 UI)
- **음식 만들기** : 재료 하나씩 클릭해서 옮겨서 뚝배기에 클릭하면 들어감
- **서빙** : 트레이 위에 국밥을 올리고(상속) 트레이 들고 손님에게 가서 손님을 클릭하면 테이블 위에 놓아짐  손님이 먹고 나가면 계산도 자동 처리
- **테이블 정리** : 빈 그릇을 퇴식구로 옮김(빈 그릇이 있으면 손님이 스폰되지 않음)
- **추후** : 계산 상호작용, 바닥 청소 상호작용

### 영업마감
- 게임 타임 멈추고 UI로 **발주 진행**
- 발주 종료하면 **자동으로 다음 날 시작**
- 발주 종료 및 다음 날 시작과 동시에 **20,000 원 소비(**고정 비용**)**
- 다음 날 시작 시 , 맵에 있는 모든 **재료, 트레이, 뚝배기, 손님** 등 삭제하고 플레이어 위치 초기화

## 플레이어
### 플레이어 기능 구현

- **기본 플레이어 조작** : WASD, 스페이스바(점프), 마우스 이동(플레이어 시점 이동)
- **상호작용 키** : 마우스 좌클릭 (Raycast)
- **아이템 버리기** : 마우스 우클릭 (플레이어에게서 분리되면서 사라짐 (재료-1))

<hr>

## 손님
### 손님 기능 구현

- 의자에 일정한 범위의 **랜덤 시간**에 한 테이블 당 한 명 씩 스폰
- 주문 완료 시 **손님 애니메이션 출력**
- 애니메이션 출력 이후 일정 시간이 지나면 손님 사라짐 (**동시에 계산까지 됨**)
이후 **빈 그릇**(재사용 불가)을 테이블에 남김
- 손님이 스폰된 시간으로부터 일정 시간마다 손님 이벤트 완료 시 **받는 평점이 줄어듦**
기본 값은 **양수**, 시간에 지남에 따라서 **음수**로 (평점이 내려가도록)
- 손님은 **주문을 받는 시간, 음식을 받는 시간**이 일정 시간을 초과하면 **가게를 떠남**(평점도 감소)

## 게임 데이터
### 음식
- **수육 국밥(10,000원) : 수육 1, 부추 1, 다데기 1, 육수 1**
- 기본 찬 : 깍두기, 김치 (**기본으로 생성**)
- 추후 다른 메뉴 추가

### 음식 재료
- **육수, 부추 , 다데기, 수육**
- 데이터 에셋을 이용한 음식 재료 설정
- 2일의 유통기한 설정 (발주 후 기간 경과 시 감소)
